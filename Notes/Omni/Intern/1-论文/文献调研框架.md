# 文献调研框架 — Stage分离与异构部署推理优化

> 目标会议：待定（请与导师确认）

## 核心发现（已通过源码验证）

**vLLM-Omni 的 disaggregation 仅针对 AR 模型，Qwen-Image 仍是单体 pipeline。**

通过阅读 vLLM-Omni 源码（`vllm_omni/diffusion/models/qwen_image/pipeline_qwen_image.py`）确认：

- vLLM-Omni 对 **Qwen3-Omni** 等 AR 模型做了 Thinker/Talker/Code2wav 的 stage 分离，支持 prefill-decode disaggregation
- 但 **Qwen-Image**（DiT 为主的文生图模型）在 vLLM-Omni 中作为 `QwenImagePipeline` 单体运行，`prepare_encode()` → `denoise_step()` × N → `post_decode()` 全在同一设备上串行执行，不做 stage 拆分
- vLLM-Omni 虽然支持 Ascend NPU 作为单设备后端（`QwenImagePipeline` 可见 NPU 支持标记），但不做跨 NPU 型号的异构部署

**本工作的差异化空间**：

1. 首次将 DiT 文生图 pipeline 拆分为 4 个独立 stage（VAE Encoder / LLM特征编码 / MMDiT生成 / VAE Decoder），填补 disaggregated inference 在扩散模型领域的空白
2. 针对昇腾 NPU 多型号 + CPU 的四级异构硬件精准匹配（vLLM-Omni 为同构 GPU pool）
3. 三级分层缓存（模型权重 / 中间特征 / 推理参数），而 vLLM-Omni 仅做 KV-cache

**关键待确认事项**：代码是否已实现？如果没有实现，论文定位为纯方案设计（design paper），投稿级别需相应调整。

## Related Work 写作框架

按以下五个子节组织，每节 3-4 段，最终落在"现有工作未解决的问题"上：

### 2.1 Efficient LLM and Multimodal Serving

- vLLM (PagedAttention) → SARATHI (chunked prefill) → vLLM-Omni (多模态 disaggregation)
- **落点**：现有 serving 系统在 DiT 文生图 pipeline 上仍是单体执行，不做 stage 拆分

### 2.2 Disaggregated Inference

- Splitwise → DistServe → Mooncake → vLLM-Omni 的 prefill-decode 分离
- **落点**：现有 disaggregation 仅限于 AR 模型的 prefill/decode 两阶段，DiT pipeline（VAE→编码→去噪→解码）的 stage 分离无人做过

### 2.3 Pipeline Parallelism for Diffusion Models

- DistriFusion → PipeFusion → xDiT
- **落点**：现有扩散模型并行方案聚焦同构 GPU 内部的 DiT 加速，未覆盖完整 pipeline（含 VAE、文本编码）的异构 stage 部署

### 2.4 Heterogeneous Deployment

- HeteGen → SiPipe → Hybrid SD
- **落点**：现有异构部署止于 CPU-GPU 二元划分，未针对昇腾多型号 NPU（310P/910C/910B）做逐 stage 亲和性匹配

### 2.5 Caching for Model Inference

- LMCache → IMPRESS → PRESERVE
- **落点**：现有缓存方案全聚焦 KV-cache，缺少适配 stage 分离架构的模型权重 + 中间特征 + 推理参数三级缓存

## 差异化定位矩阵

| 维度 | vLLM-Omni | 本工作 |
|------|-----------|--------|
| Stage 分离对象 | AR 模型（Qwen3-Omni Thinker/Talker） | **DiT 文生图 pipeline**（VAE Encoder / LLM编码 / MMDiT生成 / VAE Decoder） |
| Qwen-Image 处理方式 | `QwenImagePipeline` 单体，单设备串行 | **拆分为 4 个独立 stage**，各自独立调度 |
| 硬件平台 | NVIDIA GPU (A100/H100) 同构 pool | **昇腾 NPU 多型号** (310P/910C/910B) + CPU 异构 |
| 硬件匹配 | 无硬件亲和性匹配（同构设备） | **四级硬件精准匹配**（算力-参数规模-耗时占比对应） |
| 缓存机制 | KV-cache (DBCache/TeaCache) | **三级缓存**（模型权重 / 中间特征 / 推理参数） |
| 调度方式 | OmniRouter + 动态批处理 | **专属任务队列** + 动态批处理 + **跨硬件异步流水线** |

**核心论点**：现有 disaggregated inference 在 AR 模型和同构 GPU 上已经成熟，但针对 DiT 文生图 pipeline 的 stage 分离 + 昇腾 NPU 多型号异构部署仍是空白。本工作填补了这一 gap。
