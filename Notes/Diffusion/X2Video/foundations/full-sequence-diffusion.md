# Full Sequence Diffusion Model：一般处理形式

> [!info] 概念定位
> Full Sequence Diffusion是一种**固定长度序列生成**的扩散模型框架，将整个序列（如视频的所有帧）作为一个整体进行建模，所有token使用相同的噪声级别，采用非因果全注意力架构。

## 🎯 核心定义

> [!important] 关键特征
> - **固定长度**：只能生成训练时预设的固定长度序列
> - **统一噪声**：所有token（帧）在去噪过程中使用**相同的噪声级别**
> - **非因果架构**：使用全注意力机制，每个token可以关注序列中的所有token（包括未来）
> - **整体建模**：直接建模整个序列的联合分布

## 🔧 一般处理流程

### 1. 前向扩散过程

```
原始序列 x₀ → 逐步添加噪声 → 纯噪声 xₖ
```

**数学表示**：
```python
q(xₖ|xₖ₋₁) = N(xₖ; √(1-βₖ)xₖ₋₁, βₖI)
```

> [!note] 关键点
> - 噪声级别 k 在整个序列中**统一**
> - 所有token同时被噪声化到相同程度
> - 前向过程是马尔可夫链

### 2. 反向去噪过程

```
纯噪声 xₖ → 逐步去噪 → 生成序列 x₀
```

**采样过程**：
```python
xₖ₋₁ = √(αₖ₋₁) * (xₖ - √(1-αₖ) * ϵθ(xₖ, k) / √(αₖ)) + σₖ * ϵ
```

> [!abstract] 去噪步骤
> 1. 从纯噪声 xₖ 开始
> 2. 使用模型预测噪声 ϵθ(xₖ, k)
> 3. 逐步去噪，更新序列
> 4. 重复直到生成干净序列 x₀

### 3. 架构特点

> [!important] 全注意力机制
> - **非因果**：每个token可以关注所有其他token
> - **无掩码**：不需要因果掩码
> - **全局一致**：确保序列内部的全局一致性
> - **并行处理**：可以并行处理所有token

## 📊 张量形状变化（以视频生成为例）

### 阶段1：输入准备

**原始视频**：
```
[batch_size, channels, frames, height, width]
# 例如：[1, 3, 81, 480, 832]
```

### 阶段2：VAE编码

**潜变量**：
```
[batch_size, z_channels, latent_frames, latent_height, latent_width]
# 例如：[1, 16, 21, 60, 104]
```

> [!note] 压缩比
> - 时间压缩：4倍（81帧 → 21帧）
> - 空间压缩：8倍（480×832 → 60×104）

### 阶段3：Patch化

**Token序列**：
```
[batch_size, num_patches, hidden_dim]
# 例如：[1, 21*30*52, hidden_dim] = [1, 32760, hidden_dim]
```

> [!abstract] Patch大小示例
> - patch_size = (1, 2, 2)
> - 时间patch=1，高度patch=2，宽度patch=2

### 阶段4：Transformer处理

**输入**：
```python
hidden_states: [batch_size, seq_len, hidden_dim]  # 潜变量序列
timestep: [batch_size]  # 统一的时间步（噪声级别）
encoder_hidden_states: [batch_size, text_len, text_dim]  # 文本条件
```

**处理过程**：
```python
for block in transformer_blocks:
    # 全注意力机制，无因果掩码
    hidden_states = block(hidden_states, encoder_hidden_states, timestep)
```

**输出**：
```python
[batch_size, seq_len, hidden_dim]
```

### 阶段5：反Patch化

**潜变量**：
```
[batch_size, z_channels, latent_frames, latent_height, latent_width]
# 例如：[1, 16, 21, 60, 104]
```

### 阶段6：VAE解码

**输出视频**：
```
[batch_size, channels, frames, height, width]
# 例如：[1, 3, 81, 480, 832]
```

## 🔄 完整流程示例

> [!tip] 以Wan2.2为例
> **输入**：
> - 文本prompt："A cat dancing"
> - 可选图像：480×832 RGB图像
> - 参数：81帧，480×832分辨率
>
> **流程**：
> 1. 文本编码："A cat dancing" → [1, 512, 4096]
> 2. 准备噪声：[1, 16, 21, 60, 104]（随机高斯噪声）
> 3. 去噪循环（40步）：
>    - 每步输入：[1, 16, 21, 60, 104] + [1, 512, 4096]
>    - 每步输出：[1, 16, 21, 60, 104]
> 4. VAE解码：[1, 16, 21, 60, 104] → [1, 3, 81, 480, 832]
>
> **输出**：
> - 视频张量：[1, 3, 81, 480, 832]

## 📈 与其他范式的对比

| 特性 | Full Sequence Diffusion | Diffusion Forcing | Teacher Forcing |
|------|------------------------|-------------------|-----------------|
| **噪声级别** | ✅ 所有token相同 | ❌ 每token独立 | ✅ 所有token相同 |
| **架构** | ✅ 全注意力（非因果） | ❌ 因果掩码 | ❌ 因果掩码 |
| **生成长度** | ✅ 固定长度 | ❌ 可变长度 | ❌ 可变长度 |
| **引导能力** | ✅ 强 | ✅ 强 | ❌ 无 |
| **全局一致性** | ✅ 强 | ⚠️ 中等 | ❌ 弱 |
| **计算效率** | ⚠️ 中等 | ✅ 高 | ✅ 高 |
| **实时生成** | ❌ 不支持 | ✅ 支持 | ✅ 支持 |

## 🎨 应用场景

> [!success] 适用场景
> 1. **视频生成**：生成固定长度的高质量视频
> 2. **图像生成**：全分辨率图像生成
> 3. **长期规划**：在强化学习中规划完整轨迹
> 4. **可控生成**：通过分类器引导生成理想轨迹
> 5. **文本生成**：可控文本生成（如指定词性）

> [!warning] 不适用场景
> 1. **实时交互**：需要逐步生成的应用
> 2. **无限长度**：需要生成任意长度序列的应用
> 3. **低延迟**：需要亚秒级延迟的应用
> 4. **流式生成**：需要流式输出的应用

## ⚠️ 局限性

> [!warning] 主要局限
> 1. **固定长度限制**：只能生成训练时的固定长度
> 2. **计算成本高**：全注意力机制计算复杂度O(n²)
> 3. **内存消耗大**：需要存储整个序列的注意力图
> 4. **无法逐步生成**：必须一次性生成整个序列
> 5. **非因果架构**：无法用于自回归生成

## 💡 优势与劣势总结

> [!tip] 优势
> - **高质量生成**：全局注意力确保序列一致性
> - **强引导能力**：支持分类器引导采样
> - **并行处理**：可以并行处理所有token
> - **理论完整**：有完整的扩散理论支持

> [!warning] 劣势
> - **长度固定**：无法生成任意长度序列
> - **计算昂贵**：长序列计算成本高
> - **实时性差**：无法用于实时应用
> - **灵活性低**：无法逐步生成或交互
