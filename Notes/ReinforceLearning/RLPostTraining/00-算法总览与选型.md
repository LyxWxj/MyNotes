# RL 后训练算法总览与选型

> 本目录为"经典 RL 后训练算法"系列笔记，2026-08 整理。配套：[[RL框架设计核心问题与项目对比]]

## 一、算法谱系

```
策略梯度（REINFORCE, 1992）
├── TRPO（2015）→ PPO（2017）─────────────── PPO 系（有 critic）
│     └── VAPO（2025）：Value Pretraining + Decoupled/Length-Adaptive GAE + Clip-Higher
├── 去掉 critic，用组内归一化代替价值基线
│     └── GRPO（2024）────────────────────── 无 critic 系
│           ├── RLOO（2024）：留一法基线（更朴素的 REINFORCE）
│           ├── REINFORCE++（2025）：+ token 级 KL + clip + 全局归一化
│           ├── DAPO（2025）：Clip-Higher + Dynamic Sampling + Token-Level Loss + Overlong Shaping
│           └── GSPO（2025）：序列级重要性比率（Qwen3）
└── 离线偏好对齐（不走 RL 采样）
      └── DPO（2023）──┬── KTO（2024）：二值信号 + 前景理论
                       └── IPO / SimPO / ORPO 等变体
```

## 二、一页选型指南

| 场景 | 首选 | 备选 |
|---|---|---|
| 通用 RLHF（对话、写作，有 RM） | PPO | DPO（离线） |
| 偏好数据只有赞/踩、数据量少 | KTO | DPO |
| 数学/代码推理，规则验证器，预算充足追求上限 | VAPO | DAPO |
| 数学/代码推理，无 critic 预算、要稳定 | GRPO / GSPO | REINFORCE++ |
| MoE 大模型、超长 CoT，怕训练崩 | GSPO | GRPO + DAPO 技巧 |
| 快速原型、算力受限 | REINFORCE++ / RLOO | GRPO |
| 离线对齐（SFT 后最后一步） | DPO | KTO |

## 四、两条主线之争

- **无 critic（GRPO 系）**：省资源、简单、稳定，但优势信号粗糙（outcome 级），样本效率低；
- **有 critic（PPO/VAPO 系）**：理论上限高、可给 token 级优势，但 critic 训练难、成本翻倍；
- **2025 的收敛**：工程技巧（Clip-Higher、Token-Level Loss、动态采样、序列级 IS）在两条路线上互相迁移，差异逐渐缩小为"要不要养一个 critic"。
