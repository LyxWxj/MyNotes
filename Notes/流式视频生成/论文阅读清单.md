## 📌 核心论文（必读）

> [!important] 高优先级

### 基础架构

- [x] **DiT: Scalable Diffusion Models with Transformers**
  - 作者：William Peebles, Saining Xie
  - 链接：[arXiv:2212.09748](https://arxiv.org/abs/2212.09748)
  - 主题：Diffusion Transformer 架构，用 Transformer 替代 U-Net
  - 重要性：⭐⭐⭐⭐⭐ 现代视频生成模型的基础架构

- [x] **Stable Diffusion / Latent Diffusion Models**
  - 作者：Rombach et al.
  - 链接：[arXiv:2112.10752](https://arxiv.org/abs/2112.10752)
  - 主题：潜空间扩散模型，高效图像/视频生成
  - 重要性：⭐⭐⭐⭐⭐ 潜空间生成范式的开创性工作

- [x] **Sora: Video generation models as world simulators**
  - 作者：OpenAI
  - 链接：[OpenAI Research](https://openai.com/research/video-generation-models-as-world-simulators)
  - 主题：视频生成作为世界模拟器，时空 patch 的 Diffusion Transformer
  - 重要性：⭐⭐⭐⭐⭐ 视频生成领域的里程碑

### 流式/自回归视频生成

- [ ] **StreamingT2V: Consistent, Dynamic, and Extendable Long Video Generation**
  - 作者：Roberto Henschel et al.
  - 链接：[arXiv:2403.14773](https://arxiv.org/abs/2403.14773)
  - 主题：长视频流式生成，短期/长期运动模块，外观刷新机制
  - 重要性：⭐⭐⭐⭐⭐ 流式视频生成的代表性工作

- [ ] **LaViDa: Streaming Text-to-Video via Causal Real-Time Inference**
  - 作者：2025
  - 链接：arXiv 搜索 "LaViDa streaming text-to-video"
  - 主题：实时流式文本到视频生成，因果自回归推理
  - 重要性：⭐⭐⭐⭐⭐ 实时流式生成的最新突破

- [ ] **Self-Forcing: Autoregressive Video Generation**
  - 链接：[arXiv:2501.06993](https://arxiv.org/abs/2501.06993)
  - 主题：自回归视频生成的自强迫训练策略，解决分布不匹配问题

### 流式音频交互（与视频流式交互高度相关）

- [ ] **Audio Interaction Model: Streaming Audio-Language Model for Real-time Interaction**
  - 作者：Zhifei Xie, Zihang Liu, Ze An et al. (NTU, NUS, CUHK)
  - 链接：[arXiv:2606.05121](https://arxiv.org/abs/2606.05121) | [Project Page](https://xzf-thu.github.io/Audio-Interaction)
  - 主题：统一的流式音频语言模型，perceive-decide-respond 实时循环
  - 关键创新：
    - **Audio Interaction Model** 范式：online 模型，端到端实时感知-语义介入-流式输出
    - **SoundFlow 框架**：流式原生数据构建、理解感知训练、异步低延迟推理
    - **StreamAudio-2M 数据集**：2.6M 项，7.4M 轮，302K 小时音频，7 大能力 28 子任务
    - **主动干预能力**：基于流式语义自主决定何时响应
  - 模型能力：实时音频指令遵循、全场景语音对话、主动帮助等 7 大能力
  - 重要性：⭐⭐⭐⭐⭐ **与流式视频生成理念高度一致**：都是 online 流式模型，强调实时交互和主动响应
  - 启发点：
    - 流式模型 vs 离线模型的根本差异
    - perceive-decide-respond 循环的设计哲学
    - 如何训练模型的主动干预能力
    - 流式数据集构建方法

## 🎧 流式交互模型研究

> [!note] 跨模态流式交互
> 流式交互不仅适用于视频，音频领域的流式交互研究对视频生成有重要启发

### 流式音频交互

- [ ] **Audio Interaction Model: Streaming Audio-Language Model for Real-time Interaction**
  - 作者：Zhifei Xie, Zihang Liu, Ze An et al.
  - 链接：[arXiv:2606.05121](https://arxiv.org/abs/2606.05121) | [Project](https://xzf-thu.github.io/Audio-Interaction)
  - 核心思想：
    - "Audio is an inherently interactive modality" - 音频是天然为实时交互而生的模态
    - 现有 LALM 是 offline 架构，与流式交互天然冲突
    - 提出 Audio Interaction Model：online 模型，统一完成实时感知-语义介入-流式输出
  - 关键技术：
    - **SoundFlow 框架**：流式原生数据构建 + 理解感知训练 + 异步 FIFO 推理
    - **StreamAudio-2M**：2.6M 项数据集，7 大能力 28 子任务
    - **Chunk-level 决策训练**：带历史回顾的流式决策
    - **异步 FIFO 推理**：首帧延迟降低 4.5 倍
  - 模型能力：
    - 实时音频指令遵循
    - 全场景语音对话
    - 主动帮助（Proactive Intervention）
    - 实时计数、多事件处理等
  - 重要性：⭐⭐⭐⭐⭐
  - **与流式视频生成的关联**：
    - 相同的 perceive-decide-respond 设计哲学
    - 相同的 online vs offline 模型范式讨论
    - 流式数据集构建方法可借鉴
    - 异步推理优化技术可迁移

### 流式交互设计模式

> [!tip] 设计哲学
> 从 Audio Interaction Model 学到的流式交互设计原则

| 设计原则 | 说明 | 视频生成应用 |
|---------|------|-------------|
| **Online 模型** | 模型本身支持流式输入输出 | 视频生成需要支持逐帧/逐块生成 |
| **Perceive-Decide-Respond** | 实时感知 → 语义决策 → 流式响应 | 视频生成：感知输入 → 决定生成内容 → 流式输出 |
| **主动干预** | 基于语义自主决定何时响应 | 视频生成：根据场景变化主动调整生成 |
| **Chunk-level 处理** | 以 chunk 为单位进行流式处理 | 视频生成：以帧/块为单位生成 |
| **异步推理** | 重叠计算和 I/O，降低延迟 | 视频生成：异步编码/解码/生成 |
