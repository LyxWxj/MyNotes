# minWM: A Full-Stack Open-Source Framework for Real-Time Interactive Video World Models

## Meta Information

- **Authors**: Min Zhao, Hongzhou Zhu, Bokai Yan, Zihan Zhou, Yimin Chen, Jun Zhu
- **Date**: 2026-05

- **Zotero Key**: U9JA2WTF

## Abstract

A full-stack open-source framework for building real-time interactive video world models. Provides an end-to-end pipeline that converts existing bidirectional T2V/TI2V video foundation models into camera-controllable few-step autoregressive world models. Instantiated on Wan2.1-1.3B and HY1.5-TI2V-8B.

## Key Contributions

1. **全栈开源框架**: 提供完整的端到端pipeline
2. **模型转换**: 将现有的双向T2V/TI2V视频基础模型转换为相机可控的少步自回归世界模型
3. **实时交互**: 支持实时交互式视频世界模型
4. **多模型实例化**: 在Wan2.1-1.3B和HY1.5-TI2V-8B上实例化
