# 世界模型是什么：定义、类型与表示空间（概念辨析）

> **范围**：世界模型的核心定义、类型全景，以及四种"表示空间"（连续潜空间 / 离散 token / 嵌入表示 / 物体槽位）的深入辨析
> **来源**：基于仓库综述 [00-综述-World-Models-Survey](00-综述-World-Models-Survey.md) 与系列笔记整理
> **动机**：澄清"WASD 交互视频 = 世界模型吗"等常见误区

---

## 一、核心定义

**一句话**：世界模型是学习**环境结构和动力学**的内部模拟器——给定当前状态和动作，预测下一状态、观测和奖励。它回答的核心问题是 **"如果我这样做，世界会怎样变化？"**，而不是"给我生成一段好看的视频"。

**形式化定义**（来自综述）：

$$p_\theta(s_{t+1}, o_{t+1}, r_t \mid s_t, a_t)$$

**三个区分性特征**（`00-综述-World-Models-Survey.md`）：

| 特征 | 含义 |
|------|------|
| **动作条件化** (Action-conditioning) | 预测特定动作下的演化，支持反事实推理（"如果当时按了 A 键会怎样"） |
| **多步展开** (Multi-step rollout) | 输出作为下一帧输入，自回归地展开任意长度轨迹 |
| **决策效用** (Utility for decision-making) | 预测结果可用于规划、策略优化或安全验证 |

---

## 二、判定清单：一个"WASD 交互视频"是不是世界模型？

"语言/图像输入 → 生成视频 + 接收 WASD 控制" 是**交互式世界模型**的典型产品形态，但"生成视频"和"接收控制"都不是充分条件。用六个问题鉴别：

1. **输入是单次 prompt，还是"观测历史 + 动作"序列？** 真世界模型吃的是 $(\text{历史帧}, \text{动作}) \to \text{下一帧}$，不是一句话。
2. **输出帧会作为下一帧的输入吗（闭环 rollout）？** 还是每段视频独立从头生成？
3. **动作影响的是"当前帧的运动"，还是"世界的未来演化"？** 松开 WASD 后世界应继续按物理规律演化。
4. **长展开中状态一致吗？** 物体不凭空消失、场景不突变、有记忆。
5. **训练目标是什么？** 是否为 next-frame / next-latent prediction，而非仅文本条件生成。
6. **（学术严格版）能用于决策吗？** 能否拿它做规划/想象/训练策略。

**分层结论**：

| 层次 | 例子 | 算不算世界模型 |
|------|------|--------------|
| 文生视频/图生视频（无控制） | Sora、Wan 纯生成 | ❌ 不是，是视频生成模型 |
| 动作条件化视频生成（状态不保持） | 很多"可控视频生成" demo | ⚠️ 弱形式 |
| 交互式世界模型（闭环 + 状态一致） | Genie 3、HY-WorldPlay、LingBot-World 2.0 | ✅ 是 |

**两个常见误区**：

- **世界模型不一定输出视频**：DreamerV3 在隐空间"想象"，JEPA 在表示空间预测——视频只是面向人的交互界面。
- **"接收 WASD"不等于学到动力学**：动作映射到脚本动画不是世界模型；反之 GameNGen/DIAMOND 用扩散逐帧预测 DOOM，画面糙却是真世界模型。

## 三、类型全景（除了交互式还有什么）

"交互式"只是按**交互性/用途**切的一个标签。同一模型可以同时属于多个类型——类型是"视角"不是"互斥标签"。

### 3.1 按表示空间分（最本质的切法）

| 类型 | 预测/生成在哪里发生 | 代表 |
|------|------|------|
| **像素/观测空间** | 直接在像素上预测下一帧 | DIAMOND、GameNGen |
| **连续隐空间** | 在紧凑的连续潜在状态里预测 | RSSM / Dreamer 系列 |
| **离散 Token 空间** | 观测转 token 后自回归预测 | IRIS、GAIA-1、Genie 系列 |
| **表示空间（JEPA）** | 不重建像素，只预测嵌入表示 | V-JEPA 2.1、LeWorldModel |
| **结构化/对象中心** | 按物体建槽位预测交互 | C-SWM、Slot Attention |
| **3D/占据空间** | 预测 3D 几何/占据场 | OccWorld、Copilot4D、Marble 1.1 |

### 3.2 按方法论家族分（怎么学/怎么推）

1. **循环潜在世界模型（RSSM）**：确定性循环状态 + 随机潜变量，DreamerV3 的基石，服务 MBRL——学来"想"的，不是拿来"看"的。
2. **Transformer 世界模型**：next-token prediction，IRIS（游戏）、GAIA-1（9B 自动驾驶模型）。
3. **扩散世界模型**：迭代去噪生成未来状态，DIAMOND、GameNGen、Copilot4D——与 DiT 推理体系直接相关。
4. **物理信息/结构化模型**：可微物理引擎、哈密顿/拉格朗日神经网络，融入守恒律。
5. **语言增强/多模态模型**：LLM-as-world-model、Qwen-AgentWorld、文本条件视频生成当作世界模拟器（Sora、Cosmos）。

### 3.3 按用途/下游分

| 类型 | 干什么用 | 代表 |
|------|---------|------|
| **交互式** | 用户实时控制世界演化 | Genie 3、HY-WorldPlay、LingBot-World 2.0 |
| **视频预测/生成式** | 无控制，纯预测下一帧或按 prompt 生成 | Sora、Cosmos（生成线） |
| **决策/规划型（MBRL）** | 在想象中练策略、在线搜索规划 | Dreamer、MuZero、TD-MPC |
| **自动驾驶/具身型** | 预测驾驶场景或机器人状态演化 | GAIA-1、OccWorld、GWM、π₀ |
| **科学模拟型** | 预测物理系统动力学 | GraphCast（天气）、NeuralGCM（气候） |
| **智能体环境型** | 为语言智能体提供可交互环境 | Voyager、Smallville |
| **3D 世界型** | 生成/扩展可探索的 3D 空间 | Marble 1.1、HY-WorldPlay R-tree |

## 四、四种"逃离像素"的表示空间详解

共同点：**都不在原始像素上预测**（像素维度太高、噪声太多）。区别在于"把像素扔掉之后剩下什么"：**压缩**（连续潜空间）、**离散化**（token）、**抽象化**（嵌入）、**结构化**（物体槽位）。

### 4.1 连续潜空间预测（RSSM / Dreamer 系）

**是什么**：一帧 256×256×3 ≈ 20 万维。先由**编码器**把观测压缩成几十维潜状态 $z_t$，**动力学预测器**只在 $z$ 上预测 $\hat{z}_{t+1}$，需要画面时才用**解码器**重建像素（RSSM 六组件见 [04-DreamerV3](04-DreamerV3.md)）。

**"紧凑"的含义**：丢掉与决策无关的细节（纹理、光照、噪声），只保留状态信息（"我在哪、什么东西在动"）。

**RSSM 混合设计**：确定性循环状态 $h_t$（记住历史）+ 随机潜变量 $z_t$（处理不确定性）。DreamerV2 发现离散类别潜变量优于连续高斯。

**具体应用**：
- DreamerV3：潜空间"想象"展开轨迹训练策略（Atari、Minecraft、水下机器人）——想象 1000 步 ≈ 真实环境 100 步，但快几个数量级。
- TD-MPC / PlaNet：机器人真实控制，决策时在潜空间短视搜索。
- **关键点**：输出不是视频，而是"下一状态 + 奖励"预测——服务于决策。

**类比**：下棋高手在脑子里"想棋"——脑中是抽象局面（几颗子、几个位置），不是像素渲染的棋盘。

### 4.2 离散 token 自回归（IRIS / GAIA-1 / Genie）

**是什么**：VQ-VAE 类 tokenizer 把每帧图像"翻译"成一串**离散 token**（如 16×16=256 个/帧，每个是码本编号），然后像 LLM 一样做 next-token prediction。

**输出是文本吗？不是。** 关键澄清：
- 输出是**离散符号**，但不是自然语言。token 是"视觉词汇"——每个编号对应一个图像块。
- 文本、图像 token、音频 token 都是"离散符号系统"，只是文本恰好是人类语言。
- token 序列要经过 tokenizer 的**解码器**才能重建成像素画面。

**具体应用**：
- IRIS：游戏（Atari）模拟——token 预测 + 策略学习。
- GAIA-1：自动驾驶（9B），预测未来驾驶场景，token 解码成视频用于规划验证。
- Genie 1/2：视频帧 token 化 + latent action 自回归。
- 视频 tokenizer 本身是 WFM 基建（Cosmos Tokenizer、Wan tokenizer 同思路）。

**类比**：把视频当"文章"，tokenizer 是"造字典 + 翻译"，Transformer 是"续写"，解码器是"翻译回画面"。

### 4.3 嵌入表示预测（JEPA 系）

**是什么**：不重建像素、不预测 token，而是让**预测器输出的向量**逼近**编码器从真实未来观测提取的向量**——只对齐表示（embedding）。

**流程**（I-JEPA，见 [02-I-JEPA](02-I-JEPA.md)）：
```
可见部分 → context encoder → 表示 z_c ──→ predictor ──→ 预测表示 ẑ
真实目标块 → target encoder → 真实表示 z_t ──→ 损失：让 ẑ ≈ z_t
```

**"嵌入表示"是什么**：神经网络把输入映射成的**高维语义向量**。同一物体、不同像素细节，向量应该接近——学的是"这是一只在跑的猫"这种语义，而不是"每根毛"。

**为什么**：预测像素是浪费——算力大多花在与"世界怎么演化"无关的纹理/光照上。JEPA 强制模型只学抽象语义，跳过重建瓶颈。

**具体应用**：
- I-JEPA：图像自监督，不用标签、不用手工数据增强。
- V-JEPA 2：大规模视频理解自监督训练。
- LeWorldModel：把 V-JEPA 当世界模型做端到端机器人控制。
- MuZero 也可视为 JEPA：潜空间只优化奖励/价值预测。

**类比**：你和朋友看同一张照片的不同部分，像素完全不同，但脑中"这是一只猫"的概念相同——JEPA 对齐的是**概念**，不是像素。

### 4.4 物体槽位（Object-centric / Slot Attention）

**是什么**：把场景**分解成若干个"槽位"（slot）**，每个槽位绑定一个物体，建模"每物体的状态 + 物体间交互"，而非整张图。

**"槽位"是什么**：一组**固定数量的可学习向量**，通过 Slot Attention（迭代注意力）自动"认领"图像中的物体——车占一槽、行人占一槽、树占一槽。之后预测 = 每个物体的下一状态（位置、速度、属性），物体独立演化 + 碰撞/遮挡交互。

**优劣势**：
- ✅ 组合泛化（会"A 推 B"和"B 推 C"就能推"A 推 C"）、数据效率、可解释（出错能定位到物体）。
- ❌ 物体数量不定时槽位分配不稳定；物体间全连接 O(N²) 扩展。

**具体应用**：
- C-SWM：物理交互学习（推箱子、碰撞、遮挡）。
- SAVi / Slot Attention for video：无监督视频物体分割、视频预测。
- 机器人场景理解：抓取前分解"有哪些物体、各自什么状态"。

**类比**：围棋用"棋子"描述局面（黑子在这、白子在那），而不是"每个像素的颜色"。状态 = 物体列表 + 属性。

## 五、对比总结

| 路线 | 像素被替换成 | 预测对象 | 典型用途 | 仓库笔记 |
|------|------------|---------|---------|---------|
| 连续潜空间 | 小向量 $z_t$ | 下一潜状态 | MBRL 决策/想象 | [04-DreamerV3](04-DreamerV3.md) |
| 离散 token | 码本编号 | 下一 token | 视频模拟、驾驶预测 | [00-综述-World-Models-Survey](00-综述-World-Models-Survey.md) |
| 嵌入表示 | 语义向量 | 对齐未来表示 | 自监督理解、机器人 | [02-I-JEPA](02-I-JEPA.md)、[03-V-JEPA-2.1](03-V-JEPA-2.1.md) |
| 物体槽位 | 物体槽向量 | 每物体下一状态 | 物理推理、视频分割 | 综述 C-SWM 条目 |

**注意**：四种路线经常混用。真正"生成画面"的世界模型主要走**离散 token + 扩散/自回归**线（Cosmos、Wan、Genie 3）；另外三条线更多服务于**理解和决策**。
