## 一、核心贡献

1. **首个稳定端到端 JEPA**：仅从原始像素训练，只需两个损失项
2. **大幅简化**：可调损失超参数从 6 个减少到 1 个
3. **高效**：~15M 参数，单 GPU 几小时训练
4. **规划速度**：比基础模型快 48×
5. **物理理解**：潜在空间编码有意义的物理结构

---

## 二、方法论

### 问题：表示坍塌

JEPA 的核心挑战——模型将所有输入映射到相同表示，平凡地满足预测目标。

现有解决方案依赖：
- 启发式正则化
- 多目标损失函数
- 外部信息源
- 架构简化

### LeWM 的解决方案：两项目标

$$\mathcal{L}_{\text{LeWM}} = \mathcal{L}_{\text{pred}} + \lambda \cdot \text{SIGReg}(Z)$$

#### 1. 预测损失 (L_pred)

- 预测和实际下一步嵌入之间的均方误差
- 使用 teacher forcing
- 激励编码器学习预测器可预测的表示

#### 2. SIGReg 正则化器

- 防止坍塌：鼓励嵌入匹配各向同性高斯分布
- **关键创新**：通过随机投影绕过高维正态性评估

**方法**：
1. 将嵌入投影到 M 个随机单位范数方向
2. 对每个一维投影应用单变量 Epps-Pulley 检验统计量
3. 根据 Cramér-Wold 定理，匹配所有一维边际 = 匹配完整联合分布

**超参数**：
- M（随机投影数，默认 1024）：影响可忽略
- λ（正则化权重，默认 0.1）：**唯一有效超参数**

## 三、架构细节

### 编码器

- **Vision Transformer (ViT-Tiny)**
- ~5M 参数
- Patch 大小 14，12 层，3 注意力头，隐藏维度 192
- [CLS] token 嵌入 → 1 层 MLP + Batch Normalization
- **关键**：需要投影步骤，因为 ViT 最后层的 Layer Normalization 会阻止防坍塌目标

### 预测器

- **Transformer**：6 层，16 注意力头，10% dropout，~10M 参数
- **动作整合**：通过 Adaptive Layer Normalization (AdaLN)
- 参数零初始化确保稳定训练
- 接收 N 帧表示历史，自回归预测下一帧
- 时间因果掩码

### 关键设计

- **无停止梯度**
- **无 EMA**
- **无额外稳定化启发式**
- 梯度流过所有组件，联合端到端优化

---

## 四、潜在规划

### 推理时规划

1. 给定初始观测
2. 随机初始化候选动作序列
3. 展开到水平 H
4. 代价函数：最终预测潜在状态与目标嵌入的 L2 距离
5. 使用 Cross-Entropy Method (CEM) 求解
   - 300 采样序列
   - 30 优化迭代
6. MPC 策略：仅执行前 K 个规划动作，然后重新规划

## 五、实验结果

### 规划效率

| 环境 | 任务 | LeWM vs PLDM | 规划速度 |
|------|------|-------------|---------|
| Push-T | 2D 操作 | +18% 成功率 | <1 秒 |
| OGBench-Cube | 3D 操作 | 竞争性 | 48× 更快 |
| Two-Room | 2D 导航 | 较弱 | - |

**vs DINO-WM**：
- LeWM 在 Push-T 上超越 DINO-WM（即使后者使用额外本体感觉输入）
- 规划快 48×（~200× 更少 token 编码观测）

### 训练稳定性

**消融**：
- 性能对随机投影数和积分节点数不敏感
- 嵌入维度需要足够但快速饱和
- 替换 ViT 为 ResNet-18 仍具竞争性

**训练曲线**：
- LeWM：平滑、单调收敛
- PLDM：七项目标显示"嘈杂和非单调行为"

## 六、物理理解量化

### 潜在空间的物理结构

**Probing**：
- 线性和非线性探针预测代理位置、块位置、块角度
- LeWM 一致性优于 PLDM
- 与 DINO-WM 竞争（后者在 ~124M 图像上预训练）

**解码**：
- 训练期间未使用的解码器可从 192 维潜在表示重建视觉场景
- 确认紧凑空间保留足够的物理状态信息

**时间路径拉直**：
- LeWM 的潜在轨迹在训练中变得越来越直（涌现现象）
- 无显式正则化
- 比 PLDM（包含专门的时间平滑项）更高的时间直度

### 违反期望框架

受发展心理学启发，测量模型的"惊讶"：

**扰动类型**：
- 视觉扰动：突然改变对象颜色
- 物理扰动：传送对象（违反物理连续性）

**结果**：
- LeWM 对物理违反分配显著更高的惊讶（p<0.01）
- 颜色扰动产生较弱、非显著增加
- 模型对物理变化比视觉变化更敏感

## 八、局限性

1. **短水平规划**：需要层次化建模（未来方向）
2. **离线数据依赖**：需要足够覆盖的数据集（大规模视频预训练可帮助）
3. **动作标签依赖**：逆动力学建模可减少需求
4. **简单环境**：SIGReg 在低内在维度环境中效果较弱

---

## 九、关键洞察

1. **两项目标足够**：预测 + 高斯正则化 = 稳定 JEPA
2. **SIGReg 的数学优雅**：通过随机投影和 Cramér-Wold 定理
3. **涌现物理理解**：时间路径拉直、违反期望检测
4. **效率惊人**：15M 参数，单 GPU，48× 更快规划
5. **端到端优势**：无需 EMA、停止梯度或冻结编码器
