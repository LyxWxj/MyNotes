## 一、核心定位

Cosmos 是一个**世界基础模型平台**，帮助开发者为 Physical AI 构建定制世界模型。

**核心理念**：Physical AI 需要两个数字孪生——自身的策略模型和世界的模型。

## 二、平台组件

### 1. 视频整理管道 (Video Curator)

**五步流程**：分割 → 过滤 → 标注 → 去重 → 分片

#### 数据集

- ~20M 小时原始视频（720p-4K）
- 处理后：~10⁸ 片段（预训练），~10⁷（微调）

| 类别 | 比例 |
|------|------|
| 驾驶 | 11% |
| 手部运动/物体操作 | 16% |
| 人类运动/活动 | 10% |
| 空间感知/导航 | 16% |
| 第一人称视角 | 8% |
| 自然动态 | 20% |
| 动态摄像机 | 8% |
| 合成渲染 | 4% |
| 其他 | 7% |

#### 过滤阶段

1. **运动过滤**：ViT 分类器移除静态/突变视频
2. **视觉质量过滤**：DOVER 模型移除底部 15%；美学阈值 3.5
3. **文字叠加过滤**：MLP 检测后期处理文字
4. **视频类型分类**：排除抽象图案、视频游戏、动画

#### 标注

- VILA-13B 模型，8 帧均匀采样
- 平均字幕：559 字符 / 97 词
- FP8 TensorRT-LLM：10× 加速

#### 去重

- InternVideo2 嵌入
- K-means 聚类 (k=10,000)
- 移除 ~30% 数据

### 2. 视频 Tokenizer (Cosmos Tokenizer)

#### 架构

- **编码器-解码器**，时间因果设计
- **小波空间操作**：2 级 Haar 小波变换
- **时空分解 3D 卷积**：2D 空间 (1×k×k) + 时间 (k×1×1)，左填充确保因果性
- **因果自注意力**
- **LayerNorm**（非 GroupNorm）

#### 两种变体

| 类型 | 离散化 | 词汇量 |
|------|--------|--------|
| 连续 Tokenizer | AE，维度 16 | - |
| 离散 Tokenizer | FSQ (8,8,8,5,5,5) | 64,000 |

#### 压缩率

| 模态 | 压缩率 |
|------|--------|
| 图像 | 8×8, 16×16 |
| 视频 | 4×8×8, 8×8×8, 8×16×16 |

#### 结果

- DAVIS 上 +4 dB PSNR
- 最高 12× 更快
- 单 A100 80GB 编码 8 秒 1080p 视频

## 三、扩散 WFM 详解

### 架构：DiT + 大量修改

**基础**：Peebles & Xie 的 DiT

**关键修改**：

1. **3D Patchification**：非重叠立方体 (p_t=1, p_h=p_w=2)
2. **混合位置嵌入**：3D 分解 RoPE（FPS 感知时间）+ 可学习绝对嵌入
3. **交叉注意力**：T5-XXL 嵌入进行文本条件化
4. **查询-键归一化**：RMSNorm 防止注意力熵坍塌
5. **AdaLN-LoRA**：低秩分解自适应层归一化投影
   - **36% 参数减少**（11B→7B）
   - 无性能损失

### 模型规格

| 规格 | 7B | 14B |
|------|-----|------|
| 层数 | 28 | 36 |
| 维度 | 4096 | 5120 |
| 注意力头 | 32 | 40 |

### 训练策略

- **联合图像/视频训练**：域特定归一化 + 帧/通道标准化
- **渐进训练**：512p/57 帧 → 720p/121 帧 → 高质量微调
- **多宽高比**：5 个宽高比桶 + 反射填充
- **混合精度**：BF16 前向/反向，FP32 参数更新
- **文本条件**：T5-XXL，零填充到 512 token
- **Video2World**：条件帧时间拼接 + 增强噪声

### 扩展性

**内存分解**（每参数）：10 字节（参数 FP32+BF16+EMA），2 字节（梯度 BF16），8 字节（优化器 FP32）

14B 模型：~280GB 参数+梯度+优化器，~310GB 激活（720p）

**并行**：
- FSDP：分片因子 64（14B）或 32（7B）
- Context Parallelism (CP)：CP_SIZE=8，P2P 变体，重叠通信和计算

## 六、关键洞察

1. **平台思维**：不是单一模型，而是完整的平台（数据→预训练→后训练→Tokenizer）
2. **AdaLN-LoRA**：36% 参数减少无性能损失的关键技术
3. **时间因果 Tokenizer**：支持流式推理
4. **联合图像/视频训练**：统一训练策略
5. **开源开放**：模型和工具全部开源
