## 一、核心定位

通用交互式文本/图像到视频世界模型，支持：
- 摄像机导航
- 已观察区域重访
- 可提示事件
- 写实、游戏、风格化领域

**性能**：8×RTX 5090 达 16 FPS

---

## 二、核心技术

### 1. E-PRoPE (Efficient Projective RoPE)

**基础**：PRoPE (Projective Positional Encoding)
- 引入摄像机间视锥关系和摄像机无关 token 位置
- 两个互补子矩阵：投影摄像机几何 + 标准 RoPE

**E-PRoPE 的改进**：
- 专注于**空间下采样 token**
- Wan2.2 5B: S=18,480 tokens → N=4,096 tokens（>4.5× 空间减少）
- 省略 RoPE 子矩阵，仅保留投影组件
  - 原因：DiT 骨干的原始注意力已提供充分的时空归纳偏置
- **结果**：~50% 训练时间减少，~30% 推理时间减少

### 2. 记忆条件场景持久性

**问题**：离开局部上下文窗口后，先前观察的内容可能改变

**记忆条件化**：
- 模型输入打包三个来源：
  - 记忆潜在帧 $z_M$
  - 近期历史帧 $z_H$
  - 噪声目标帧 $z_C$
- 仅对目标帧计算损失

**记忆检索**：
- 使用**摄像机姿态和视图重叠**（非时间距离）选择相关历史帧
- 检索帧获得对应原始时间位置的 RoPE 嵌入
- NTK-aware RoPE 缩放和 YaRN 处理大时间间隔

**曝光偏差缓解**：
- 仅扰动条件 token，保持目标潜在干净
- 教模型"在有帮助时利用采样记忆帧，在记忆有错误时回退到学习先验"

### 3. 事件指令调优

**独特能力**：可组合事件控制
- 多个对象出现、动作、交互
- 结构化指令

**支持的控制类型**：
- 可提示事件
- 对象级事件
- 区域引导事件
- 多实体组合
- 对象间交互

**训练**：
- 微调完整 DiT，无架构变化
- 通过文本条件接口输入事件语义
- 保守更新 + 严格梯度裁剪

### 4. 自回归长视频生成 + 蒸馏

**流程**：
1. **因果强迫** (Causal Forcing)：高质量视频数据上微调
2. **长展开适应**：Infinity-RoPE 扩展上下文
3. **DMD-forcing**：摄像机控制的学生展开匹配双向教师

**I2V 质量保持**：
- 每个 DMD 窗口的第一潜在帧解码后馈送给教师作为图像条件

**效果**：稳定长达一分钟的长时推理，保持摄像机可控性

### 5. 强化学习对齐

**问题**：DMD 蒸馏可能降低视频质量和削弱摄像机可控性

**解决方案**：DiffusionNFT + 渐进更新策略

**流程**：
1. 当前模型生成长水平展开候选
2. 采样短片段进行奖励计算
3. 两个奖励模型：摄像机控制准确性 + 视觉质量
4. KL 正则化平衡奖励并保持接近 DMD 蒸馏模型

## 三、数据管道

### 三个数据源

1. **UE 生成数据**：UE5，三种观察模式（第一人称、第三人称、事件子集）
2. **真实世界数据**：SpatialVID, RealEstate10K, Sekai, DL3DV
3. **游戏数据**：Sekai-Game, OmniWorld-Game

### 三阶段质量控制

1. **基础过滤**：时长、文字叠加、视觉变化
2. **几何摄像机姿态清理**：SLERP 稀疏化、平移尖峰检查
3. **视频字幕和属性标注**：全局字幕 + 美学/运动/场景/风格标签

### 事件指令数据

- 高质量可见状态变化片段
- 层次化字幕策略
- 全局描述 + 密集时间对齐实体级事件记录

---

## 四、推理加速

### 自回归流式推理

- 逐块生成
- 每块从噪声开始，在文本提示、块相对摄像机轨迹和滚动 KV Cache 下去噪
- 摄像机控制使用块相对参数化

### 优化技术

| 组件 | 优化 |
|------|------|
| DiT 去噪 | INT8 SageAttention, FP8 FFN, 序列并行, Triton 融合核, TeaCache |
| VAE 解码 | 75% 剪枝 (~0.25s/块), torch.compile, ParaVAE 并行 |
| 服务 | 异步流水线并行（VAE 解码 k 与 DiT 去噪 k+1 重叠） |

## 六、关键洞察

1. **E-PRoPE**：高效摄像机控制的关键（4.5× token 减少）
2. **记忆 > 时间距离**：基于视图重叠的检索更有效
3. **事件指令调优**：独特的可组合事件控制能力
4. **全栈思维**：数据→训练→评估→推理加速必须组织
5. **RL 对齐**：蒸馏后需要恢复质量和可控性
