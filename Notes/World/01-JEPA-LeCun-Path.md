## 一、核心论点

LeCun 认为当前 LLM/生成式 AI 缺乏真正的理解，因为它们预测 token，而 JEPA 旨在预测**抽象潜在表示**，从而实现更高效、灵活的推理。

**核心主张**：通往自主机器智能的路径需要一个能学习世界模型的架构，该模型在**表示空间**而非**像素空间**中预测。

---

## 二、认知架构：六个模块

LeCun 提出一个模块化认知架构：

### 1. 配置器 (Configurator)
- **元认知模块**，根据任务调整其他模块
- 充当"执行控制"，调节注意力和资源分配
- 类似人脑的前额叶皮层功能

### 2. 感知模块 (Perception Module)
- 将感官输入编码为抽象表示
- 处理视觉、听觉、触觉等多模态输入
- 输出紧凑的潜在状态

### 3. 世界模型 (World Model)
- **架构的核心组件**
- 预测未来的抽象表示（非原始输入）
- 基于动作条件化的预测
- 支持多步想象展开

### 4. 代价模块 (Cost Module)
- 计算智能体的驱动/奖励
- 包含内在动机（好奇心）和外在任务奖励
- 类似人脑的情绪/价值系统

### 5. 行为模块 (Actor Module)
- 规划和产生动作
- 基于世界模型的想象进行规划
- 执行模型预测控制 (MPC)

### 6. 短期记忆 (Short-Term Memory)
- 存储最近的状态表示
- 维护时间连续性
- 支持工作记忆功能

## 三、JEPA 框架详解

### 核心思想

**联合嵌入预测架构** (Joint-Embedding Predictive Architecture)：

- 在**表示空间**中预测，而非像素/生成空间
- 避免建模无关细节的浪费
- 使用联合嵌入方法（VICReg, I-JEPA, V-JEPA）学习好的表示

### 为什么拒绝生成式模型？

| 生成式模型 | JEPA |
|-----------|------|
| 预测像素/token | 预测抽象表示 |
| 需要建模所有细节 | 只建模决策相关信息 |
| 计算昂贵 | 高效 |
| 容易累积误差 | 更鲁棒 |

### 关键优势

1. **信息效率**：不浪费容量建模无关细节
2. **抽象推理**：在语义层面操作
3. **可扩展性**：表示空间预测更容易扩展
4. **物理直觉**：潜在空间可编码物理规律

## 四、层次化规划

### 视角 1：模型预测控制 (MPC)

```
当前状态 → 世界模型想象多条轨迹 → 选择最优动作序列 → 执行第一步 → 重复
```

### 视角 2：层次化规划

- **高层规划**：在抽象表示空间中规划长期目标
- **低层执行**：在详细表示空间中执行具体动作
- 类似人类的"先想大方向，再想具体步骤"

### 与 Active Inference 的联系

- 都强调内部模型的重要性
- 都使用预测来指导行为
- JEPA 提供了更具体的架构框架

## 五、能量基模型 (Energy-Based Models) 视角

### EBM 框架

JEPA 可以从能量基模型的角度理解：

- **兼容输入对**：低能量（高兼容性）
- **不兼容输入对**：高能量
- 学习目标：让兼容对的能量低于不兼容对

### 联合嵌入架构 (JEA)

- 学习兼容输入的相似嵌入
- 主要挑战：表示坍塌（能量景观平坦）
- 解决方案：对比损失、非对比冗余最小化、聚类、非对称架构

### 生成式架构

- 从信号 $x$ 重建信号 $y$，使用解码器
- 通过限制 $z$ 的信息容量避免坍塌

### JEPA 的独特之处

- **在嵌入空间而非输入空间应用损失函数**
- **不寻求对特定数据增强不变的表示**
- 而是寻求**在给定额外信息 $z$ 时相互预测的表示**

## 六、与大脑的类比

### 皮层-基底节-丘脑回路

- **皮层**：世界模型（预测未来状态）
- **基底节**：行为模块（选择动作）
- **丘脑**：信息中继和协调

### 预测编码

- 大脑不断预测下一时刻的感官输入
- 预测误差驱动学习
- JEPA 的表示空间预测与此类似

---

## 七、技术挑战

### 1. 表示坍塌

- 模型映射所有输入到相同表示
- 需要正则化（VICReg、停止梯度、EMA）

### 2. 多步预测误差累积

- 长程展开中误差复合
- 需要不确定性估计和自适应规划

### 3. 从观测学习因果结构

- 相关性 ≠ 因果性
- 需要干预和反事实推理

### 4. 可扩展性

- 从简单环境到复杂现实世界
- 需要基础模型级别的缩放

## 九、关键洞察

1. **表示空间预测 > 像素空间预测**：避免建模无关细节
2. **联合嵌入 > 生成式**：更高效、更鲁棒
3. **模块化架构**：配置器、感知、世界模型、代价、行为、记忆
4. **层次化规划**：在不同抽象层次进行规划
5. **能量基视角**：统一理解 JEPA 的理论框架

## 十、与你研究方向的关联

作为 DiT 推理系统优化方向的研究者：

1. **JEPA 的表示空间预测**可能比扩散模型的像素空间预测更高效
2. **LeWorldModel** 证明了 JEPA 可以端到端训练，仅需 15M 参数
3. **规划效率**：JEPA 比基础模型快 48×
4. **潜在研究方向**：将 JEPA 的高效表示学习与 DiT 的生成能力结合
