# 世界模型推理框架调研（2026-08）

> **范围**：截至 2026 年 8 月的世界模型推理/服务化基础设施盘点
> **视角**：从 **推理引擎、流式生成、系统层** 出发，与 DiT Serving 调研（[业界现状调研报告](../Diffusion/ServingSystem/业界现状调研报告.md)）衔接
> **一句话结论**：世界模型推理正在从"跑通 demo"走向"统一引擎 + 流式实时交互"，主流路线分为**统一推理基础设施、通用多模态引擎、模型厂商自带栈、测试时扩展研究、国产 NPU 线**五类。

---

## 一、总体格局

2026 年的世界模型（World Foundation Model, WFM）推理呈现三条主线：

| 主线 | 代表 | 特点 |
|------|------|------|
| **统一推理基础设施** | WorldFoundry | 一个引擎跑所有 WFM + VLA，附评测 |
| **通用多模态引擎** | SGLang Diffusion、vLLM-Omni | 复用 LLM 推理基建（调度/KV 缓存/OpenAI 兼容 API），扩展 diffusion 执行 |
| **模型厂商自带栈** | Cosmos+NeMo、HY-WorldPlay、Qwen-AgentWorld、Marble API、Genie 3 | 与模型深度耦合，主打实时交互 |
| **测试时扩展研究** | SWIFT、OpenWorldLib、LoopWM | 探索 WFM 的 scaling 与统一抽象 |
| **国产 NPU 线** | MoWorld | 昇腾全栈、成本优势 |

关键趋势：**交互式/实时（streaming）成为第一诉求**；**逐步执行（step-level execution）取代整段去噪**；**缓存（TeaCache/Cache-DiT）成为标配**；**NPU 与多后端 attention 被显式支持**。

---

## 二、统一推理基础设施

### 1. WorldFoundry（OpenEnvision，2026-07 开源）

> **仓库**: https://github.com/OpenEnvision/WorldFoundry

- 定位：**统一世界模型推理与评测基础设施**，一个入口跑多个模型。
- 模型覆盖：Wan、HunyuanVideo、LTX2、Cosmos3、Helios 等主流世界模型，并支持 VLA（Vision-Language-Action）。
- 工程特性：
  - 内置 **TUI / CLI / Studio** 三种交互界面；
  - **统一 attention 后端**：FlashAttention-2/3、SageAttention、xFormers 可切换；
  - **NVFP4 量化**、**Context Parallel / Sequence Parallel** 分布式支持；
  - **Benchmark Zoo**：内置评测基准与复现脚本。
- 意义：把"评测 + 推理 + 交互"收进一个开源平台，降低 WFM 横向对比成本。

---

## 三、通用多模态推理引擎（diffusion 进入 LLM 基建）

### 2. SGLang Diffusion

> **文档**: https://docs.sglang.io/docs/sglang-diffusion

- SGLang 官方 diffusion 分支，面向图像/视频生成 serving。
- 支持模型：Wan、Hunyuan、Qwen-Image、FLUX 等。
- 关键能力：
  - **sgl-kernel** 高性能算子；
  - **Cache-DiT / TeaCache** 缓存加速；
  - **OpenAI 兼容接口 `/v1/videos`**；
  - **LingBot-World 2.0 实时 WebSocket 会话推理教程**已发布（与仓库内 [12-LingBot-World-v2](12-LingBot-World-v2.md) 直接相关）；
  - Cosmos3-Nano 也加入了 SGLang serving 支持。

### 3. vLLM-Omni

> **文档**: https://docs.vllm.ai/projects/vllm-omni/ （`.../dit_module/` 部分）

- 定位：**统一全模态推理引擎**——自回归 LLM + diffusion + TTS 同一套 serving 栈。
- 核心设计（与 DiT Serving 调研中"阶段解耦"思路一致）：
  - **StepScheduler 逐步调度**：`prepare_encode → denoise_step → step_scheduler → post_decode`，把去噪拆成可调度的步；
  - **TeaCache 等缓存**机制；
  - attention 后端：FlashAttention / SageAttention / SDPA；
  - **NPU 支持（HCCL）**；
  - OpenAI 兼容 `/v1/videos`。
- 代码结构：`vllm_omni/diffusion`（详见 [Notes/vLLM-omni](../vLLM-omni/) 系列笔记）。

## 四、模型厂商自带推理栈

### 4. NVIDIA Cosmos-Predict1 + NeMo

> **文档**: https://docs.nvidia.com/cosmos/latest/predict1/

- Cosmos-Predict1 是一组 **WFM 集合**（扩散 + 自回归两条模型线），配 NeMo 完成**推理与后训练**。
- 硬件基线：推荐 H100 / A100-80GB。
- 与仓库已有 [07-Cosmos](07-Cosmos.md)、[07-Cosmos3-Architecture-Deep-Dive](07-Cosmos3-Architecture-Deep-Dive.md) 笔记衔接。

### 5. 腾讯混元世界模型 1.5 / HY-WorldPlay（2025-12 开源）

> **仓库**: https://github.com/Tencent-Hunyuan/HY-WorldPlay

- 实时世界模型：**24FPS / 720P**。
- 系统级优化点：
  - **流式推理优化**（长时交互的关键）；
  - **Context Forcing 蒸馏**（用自回归式 teacher 蒸馏出实时模型）；
  - **重构记忆机制**（长上下文记忆管理）；
  - **R-tree 3D 场景**组织。

### 6. Qwen-AgentWorld（QwenLM，2026-06）

- **原生语言世界模型（LWM）**，把世界建模放进语言模型本身。
- 覆盖 **7 个统一 agent 域**（游戏、具身、网页、工具等）。
- 工程友好：官方支持 **SGLang / vLLM / HF transformers** 三种推理后端。
- 效果：Qwen-AgentWorld-397B-A17B 在 AgentWorldBench 得分 **58.71**，超过 GPT-5.4（58.25）。

### 7. World Labs Marble 1.1（World API）

> **文档**: https://docs.worldlabs.ai | 报道: https://en.theblockbeats.news/flash/340172

- 商业化世界模型 API（World API），单次推理约 **5 分钟**。
- Marble 1.1-plus 支持**自动扩展 3D world 空间**（探索到哪里，世界生成到哪里）。

### 8. Google DeepMind Genie 3（2025-08）

> **博客**: https://deepmind.google/blog/genie-3-a-new-frontier-for-world-models/

- 实时 3D 交互世界模型：**720p / 24FPS**，约 **1 分钟记忆**。
- 架构栈（社区分析）：**visual tokenizer + dynamics model + action interface + renderer**。
- 社区构建的推理实现约 15–20 FPS；Genie 3.5 无可靠公开信息，勿混淆于 Gemini 3.5。

## 五、研究性：测试时扩展与统一抽象

### 9. SWIFT：WFM 测试时扩展（arXiv 2503.24320）

> **论文**: https://arxiv.org/abs/2503.24320 | **代码**: https://github.com/Mia-Cong/SWIFT

- 首个面向 **WFM 的 test-time scaling 框架**。
- 三个组件：**fast tokenizer**（加速候选生成）、**Top-K pruning**（剪枝搜索空间）、**beam search**。
- 基于 Cosmos 验证。
- ⚠️ 注意：同名 SWIFT-WM（另一团队）不在此列。

### 10. OpenWorldLib（北大 DCAI + 快手可灵等，arXiv 2604.04707）

> **论文**: https://arxiv.org/abs/2604.04707 | **仓库**: https://github.com/OpenDCAI/OpenWorldLib | 中文介绍: https://hub.baai.ac.cn/view/54414

- 统一世界模型推理框架，三层抽象：**模型抽象层 / 推理引擎层 / 交互管理层**。
- 能力分四大模块：**Reasoning / Synthesis / Representation / Memory**。

### 11. LoopWM（FaceMind，架构方向）

- 循环式世界模型：**隐空间迭代 + Early Exit + Deferred Decoding**。
- 宣称**线性 test-time scaling** 与 **2 个数量级参数效率提升**（待独立验证）。
- 属架构创新，不算 serving 框架，但影响未来推理形态。

## 六、国产 NPU 线

### 12. MoWorld（魔芯科技）

- 首个**全栈国产 NPU（昇腾）实时交互世界模型**。
- 14B MoE 达到 **>50 FPS** 实时推理；宣称推理成本比 GPU 低约 **70%**。
- 提出 **Flash World Model** 概念（流式 + 缓存友好），对国产化部署参考价值大。

## 八、设计要点提炼（推理系统视角）

| 维度               | 现状共识                                      | 代表实现                                                |
| ---------------- | ----------------------------------------- | --------------------------------------------------- |
| **执行粒度**         | 从整段去噪走向 **step-level execution / 逐步调度**   | vLLM-Omni StepScheduler、SGLang Diffusion            |
| **缓存**           | TeaCache / Cache-DiT 类缓存为标配               | SGLang Diffusion、vLLM-Omni                          |
| **Attention 后端** | FA2/FA3、SageAttention、xFormers、SDPA 统一可切换 | WorldFoundry、vLLM-Omni                              |
| **量化**           | NVFP4 等低比特进入推理栈                           | WorldFoundry                                        |
| **并行**           | Context Parallel / Sequence Parallel      | WorldFoundry                                        |
| **流式交互**         | WebSocket 会话式推理成为标准接口                     | SGLang Diffusion（LingBot-World 2.0 教程）、HY-WorldPlay |
| **API 兼容**       | 对齐 OpenAI `/v1/videos` 等接口                | SGLang Diffusion、vLLM-Omni                          |
| **评测**           | 推理与 benchmark 一体化                         | WorldFoundry Benchmark Zoo                          |
| **NPU**          | 昇腾（HCCL）等国产后端被显式支持                        | vLLM-Omni、MoWorld                                   |
