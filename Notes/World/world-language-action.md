# World-Language-Action Model for Unified World Modeling, Language Reasoning, and Action Synthesis

## Meta Information

- **Authors**: Yi Yang, Zhihong Liu, Siqi Kou, Yiyang Chen, Yanzhe Hu, Jianbo Zhou, Boyuan Zhao, Zhijie Wei
- **Date**: 2026-06
- **arXiv ID**: 2606.05979
- **DOI**: 10.48550/arXiv.2606.05979
- **URL**: https://arxiv.org/abs/2606.05979
- **Zotero Key**: 4F8GBLFX

## Abstract

Proposes world-language-action (WLA) models as a new class of embodied foundation models. Uses an autoregressive Transformer backbone predicting next state, comprising the semantic-level textual intention and complementary fine-grained physical dynamics. WLA-0 achieves 40 ms per inference on an NVIDIA RTX 5090.

## Key Contributions

1. **WLA模型**: 提出world-language-action模型作为新的一类具身基础模型
2. **统一建模**: 统一世界建模、语言推理和动作合成
3. **自回归Transformer**: 使用预测下一状态的自回归Transformer骨干网络
4. **高效推理**: WLA-0在RTX 5090上实现40ms推理

## Method

- 自回归Transformer骨干网络
- 语义级文本意图(semantic-level textual intention)
- 细粒度物理动态(fine-grained physical dynamics)
- 下一状态预测

## Results

- WLA-0推理速度：40ms/inference (RTX 5090)
- 统一世界建模、语言推理和动作合成
