# Latent Spatial Memory for Video World Models

## Meta Information

- **Authors**: Weijie Wang, Haoyu Zhao, Yifan Yang, Feng Chen, Zeyu Zhang, Yefei He
- **Date**: 2026-06
- **arXiv ID**: 2606.09828
- **DOI**: 10.48550/arXiv.2606.09828
- **URL**: https://arxiv.org/abs/2606.09828
- **Zotero Key**: TCDLVVP2

## Abstract

Introduces latent spatial memory for video world models, a persistent 3D cache that stores scene information directly in the diffusion latent space. Achieves 10.57x faster end-to-end video generation and 55x reduction in memory footprint vs. explicit 3D baselines.

## Key Contributions

1. **潜在空间记忆**: 提出在扩散潜在空间中存储场景信息的持久3D缓存
2. **显著加速**: 实现10.57倍的端到端视频生成加速
3. **内存优化**: 相比显式3D基线减少55倍内存占用
4. **高效世界模型**: 提升视频世界模型的效率

## Method

- 潜在空间中的持久3D缓存
- 扩散潜在空间(Diffusion Latent Space)
- 场景信息存储
- 高效视频生成

## Results

- 10.57x faster end-to-end video generation
- 55x reduction in memory footprint
- vs. explicit 3D baselines
