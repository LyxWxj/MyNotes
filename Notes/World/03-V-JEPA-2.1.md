# V-JEPA 2.1: Unlocking Dense Features in Video Self-Supervised Learning (2026)

> **论文**: V-JEPA 2.1: Unlocking Dense Features in Video Self-Supervised Learning
> **作者**: Lorenzo Mur-Labadia, Matthew Muckley, Amir Bar, Mido Assran, Koustuv Sinha, Mike Rabbat, Yann LeCun, Nicolas Ballas, Adrien Bardes
> **来源**: arXiv 2603.14482 | Meta FAIR
> **分类**: cs.CV

---

## 一、核心问题

现有 JEPA 方法在**全局语义理解**方面表现优秀，但**密集空间结构**（定位、几何、跟踪）较弱。

**假设**：对未掩码区域（上下文 token）缺乏监督导致模型只聚合全局信息，不编码局部信息。

---

## 二、四个关键创新

### 1. 密集预测损失 (Dense Predictive Loss)

**核心发现**：将预测损失扩展到整个输入（掩码和非掩码）显著改善密集表示。

$$\mathcal{L}_{\text{dense}} = \mathcal{L}_{\text{predict}} + \mathcal{L}_{\text{ctx}}$$

**上下文损失加权方案**：

$$\lambda_i = \lambda / \sqrt{d_{\min}(i, M)}$$

- 按到掩码 token 的最小时空距离的平方根倒数加权
- 强调掩码区域附近的 patch，强制局部连续性
- 渐进式预热（epoch 50-100）稳定训练

### 2. 深度自监督 (Deep Self-Supervision)

- 在**多个中间编码器层**应用自监督目标
- 三个中间块输出 + 最终输出 → MLP 融合 → 预测器产生四个层次的预测
- 每个层次都应用预测和上下文损失

**效果**：
- 恢复全局理解（SSv2: 62.5→72.0）
- 同时保持密集任务改进（ADE20K: 33.9→38.6 mIoU）

### 3. 多模态 Tokenizer (Multi-Modal Tokenizer)

- **视频**：3D 卷积 (16×16×2)
- **图像**：2D 卷积 (16×16)
- 可学习模态 token
- 消除时间重复，提升效率

### 4. 有效缩放

- VisionMix-163M：LVD-142M + 视频源
- 最优比例：128 视频片段 + 2304 图像 / 全局 batch
- 模型缩放：ViT-L (300M) → ViT-G (2B)

---

## 三、架构细节

```
输入 → 模态特定 patch 嵌入 → 掩码损坏 → x-编码器（多层表示）
     → MLP 融合 → 与掩码 token 拼接 → 预测器 → 多层预测
```

- **训练**：135,000 迭代，预热-常数调度
- **视频**：16 帧，256×256
- **图像**：256×256
- **冷却阶段**：12,000 迭代，高分辨率（视频 64 帧 384×384；图像 512×512）

## 四、实验结果

### 核心指标对比

| 任务 | 指标 | V-JEPA 2 | V-JEPA 2.1 | 提升 |
|------|------|----------|------------|------|
| Ego4D 短期交互预测 | mAP | - | **7.71** | +35% vs SOTA |
| EPIC-KITCHENS 动作预测 | R@5 | - | **40.8** | +2.8% |
| 真实机器人抓取 | 成功率 | 60% | **80%** | +20% |
| Tartan Drive 导航 | ATE↓ | - | **5.687** | SOTA |
| NYUv2 深度估计 | RMSE↓ | 0.682 | **0.307** | -55% |
| SSv2 动作识别 | 准确率 | 72.8 | **77.7** | +4.9% |
| ImageNet-1K | Top-1 | 82.2 | **85.5** | +3.3% |
| ADE20K 语义分割 | mIoU | 22.2 | **47.9** | +25.7% |

### 消融研究

| 组件 | IN1K | SSv2 | NYU RMSE↓ | ADE20K |
|------|------|------|-----------|--------|
| V-JEPA 2 基线 | 82.2 | 72.8 | 0.682 | 22.2 |
| + 上下文损失 | 72.6 | 62.5 | 0.474 | 33.8 |
| + 多层预测 | 80.8 | 72.1 | 0.463 | 38.6 |
| + VisionMix | 81.6 | 72.6 | 0.418 | 40.8 |
| + 多模态 Tokenizer | 81.6 | 72.6 | 0.415 | 41.4 |
| + 模型缩放 | 84.8 | 76.1 | 0.365 | 47.1 |
| + 冷却 | 85.5 | 77.7 | 0.307 | 47.9 |

**关键观察**：
- 上下文损失单独使用会损害分类（82.2→72.6）
- 深度自监督恢复分类性能（72.6→80.8）
- 各组件逐步叠加，效果累加

## 六、机器人规划应用

### 抓取任务

- 在 Droid 数据集上训练动作条件预测器
- 零样本部署在 Franka Panda 机器人上
- V-JEPA 2.1: 80% 抓取成功率（8 步展开）
- V-JEPA 2: 60%（长程展开反而退化）

### 导航任务

- 训练 Conditional Diffusion Transformer
- 仅需 8 去噪步骤（vs SD-VAE 的 128 步）
- **10× 更快规划**，精度相当或更好

---

## 七、关键洞察

1. **密集特征需要显式监督**：仅对掩码区域训练不够
2. **深度自监督是关键**：在多个层次应用目标
3. **全局与密集可以兼得**：通过精心设计的损失平衡
4. **缩放有效**：ViT-G 带来显著改进
5. **实用价值**：机器人抓取和导航的实际改进

---
