## 摘要

介绍了 Simplex Rotary Agent Encoding，这是一种 3D RoPE 的无参数扩展，将智能体表示为正单纯形的顶点。使用稀疏中心注意力（Sparse Hub Attention）将跨智能体注意力从二次复杂度降低到线性复杂度。蒸馏的因果学生模型实现了 24 FPS 的动作响应生成。

## 核心贡献

1. **Simplex Rotary Agent Encoding**: 3D RoPE 的无参数扩展，将智能体表示为正单纯形的顶点
2. **Sparse Hub Attention**: 将跨智能体注意力从 O(n²) 降低到 O(n)
3. **因果学生蒸馏**: 蒸馏的因果学生模型实现 24 FPS
4. **多智能体建模**: 超越两玩家的多智能体世界建模
5. **几何表示**: 使用几何方法表示智能体关系

## 方法

### Simplex Rotary Agent Encoding

#### 核心思想
- **正单纯形**: 将智能体表示为正单纯形的顶点
- **无参数**: 不引入额外参数
- **几何保持**: 保持智能体间的几何关系

#### 技术实现
- **3D RoPE 扩展**: 扩展 3D Rotary Position Encoding
- **顶点映射**: 将智能体映射到单纯形顶点
- **相对位置**: 通过顶点关系编码相对位置

#### 数学表示
- **正单纯形**: n 维空间中的正单纯形有 n+1 个顶点
- **顶点坐标**: 每个顶点有唯一的坐标表示
- **距离关系**: 顶点间距离保持一致

### Sparse Hub Attention

#### 问题
- **二次复杂度**: 传统注意力机制的 O(n²) 复杂度
- **多智能体**: 智能体数量增加时计算量急剧增长
- **实时性**: 难以满足实时交互需求

#### 解决方案
- **中心节点**: 选择中心节点（Hub）作为信息枢纽
- **稀疏连接**: 智能体只与中心节点连接
- **线性复杂度**: 将复杂度降低到 O(n)

#### 实现细节
- **中心选择**: 动态或静态选择中心节点
- **信息聚合**: 中心节点聚合所有智能体信息
- **信息分发**: 中心节点分发信息给所有智能体
