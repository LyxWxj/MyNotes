# obsrepo

个人知识库，基于 [Tolaria](https://github.com/refactoringhq/tolaria) 构建的 Markdown 笔记仓库。

## 目录结构

```
obsrepo/
├── Notes/                  # 笔记主体
│   ├── CPP/               # C++ 相关内容
│   ├── Diffusion/         # 扩散模型
│   ├── LargeLanguageModel/ # 大语言模型
│   └── ReinforceLearning/ # 强化学习
├── blog/                   # 博客相关
└── DS Panorama/            # 数据结构全景
```

## 主要内容

- **计算机科学基础**：数据结构与算法、操作系统、计算机网络、数据库
- **机器学习与深度学习**：基础理论、扩散模型、大语言模型、强化学习
- **计算机图形学**：渲染管线、光线追踪、着色器
- **计算机视觉**：图像增强、特征提取、模式识别
- **项目笔记**：EssentialDL（自研深度学习框架）、室内定位、三维拓扑查询等
